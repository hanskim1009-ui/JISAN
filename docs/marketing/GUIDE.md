## 1. 이번 주: 검색엔진 등록과 방문 분석

### 1-1. 구글 서치콘솔 등록
구글 검색에 사이트가 잘 잡히는지 보고, 문제를 알려 주는 무료 도구입니다.
1. 사무소 구글 계정으로 로그인한 뒤 https://search.google.com/search-console 에 들어갑니다.
2. '속성 추가'를 누르고 **'URL 접두어'** 칸에 `https://jisanlaw.com` 을 입력합니다.
   - 왼쪽 '도메인' 방식은 DNS 설정이 필요해서 더 번거롭습니다.
3. 소유권 확인 방법 중 **'HTML 태그'**를 고릅니다.
4. 화면에 `<meta name="google-site-verification" content="abc123..." />` 같은 줄이 나옵니다. **content="..." 안의 값**만 복사해 Claude에게 전달합니다.
5. Claude가 반영·배포했다고 알려 드리면 서치콘솔로 돌아가 **'확인'**을 누릅니다.
6. 확인이 끝나면 왼쪽 메뉴 **'Sitemaps'**에 `sitemap.xml` 을 입력하고 제출합니다.
7. 며칠~2주 뒤부터 '실적' 메뉴에서 어떤 검색어로 몇 번 보였는지 확인할 수 있습니다.

### 1-2. 네이버 서치어드바이저 등록
네이버 검색(웹문서·블로그 외 '사이트' 영역)에 홈페이지가 나오게 하는 도구입니다.
1. 사무소 네이버 계정으로 https://searchadvisor.naver.com 에 들어가 **'웹마스터 도구'**를 누릅니다.
2. 사이트 등록 칸에 `https://jisanlaw.com` 을 입력합니다.
3. 소유 확인 방법에서 **'HTML 태그'**를 고르고, `content="..."` 안의 값을 Claude에게 전달합니다.
4. 반영·배포 뒤 **'소유확인'**을 누릅니다.
5. 사이트를 고른 뒤 **'요청' → '사이트맵 제출'**에서 `https://jisanlaw.com/sitemap.xml` 을 제출합니다.
6. 같은 '요청' 메뉴의 **'RSS 제출'**에서 `https://jisanlaw.com/rss.xml` 을 제출합니다. 새 칼럼을 올리면 네이버가 빨리 가져갑니다.
7. **'검증' → '웹 페이지 최적화'**에 `https://jisanlaw.com` 을 넣어 문제가 없는지 한 번 확인합니다.

### 1-3. 빙 웹마스터 도구 등록
마이크로소프트 빙 검색과, 빙을 쓰는 서비스(ChatGPT 검색 등)에 나오게 합니다.
1. https://www.bing.com/webmasters 에 마이크로소프트 계정이나 구글 계정으로 로그인합니다.
2. **'Import from Google Search Console'**을 고르면 1-1에서 등록한 사이트와 사이트맵을 그대로 가져옵니다. 이 방법이면 코드를 따로 받을 필요가 없습니다.
3. 직접 등록하는 경우에는 'HTML Meta Tag' 방식의 `content` 값(`msvalidate.01`)을 Claude에게 전달합니다.

### 1-4. 구글 애널리틱스 4 (방문 통계)
몇 명이 어느 페이지를 보고, 어디서 메신저 버튼을 눌렀는지 보는 도구입니다.
> **먼저** 2번 항목(개인정보처리방침 확정)을 끝낸 뒤 켜야 합니다. 쿠키로 방문 정보를 모은다는 내용이 방침에 있어야 합니다.
1. https://analytics.google.com 에서 **'측정 시작'**을 누릅니다.
2. 계정 이름(예: 법률사무소 지산), 속성 이름(예: jisanlaw.com)을 넣습니다. 보고 시간대는 **대한민국**, 통화는 **원**으로 고릅니다.
3. 업종·규모·목적은 해당하는 것을 고릅니다(통계에 영향 없음).
4. 데이터 스트림에서 **'웹'**을 고르고 URL `https://jisanlaw.com`, 스트림 이름 `jisanlaw` 를 넣습니다.
5. 만들어진 화면의 **측정 ID**(`G-` 로 시작)를 Claude에게 전달합니다. 설치 코드는 필요 없습니다.
6. (권장) 관리 → 데이터 보관에서 보관 기간을 **14개월**로 바꿉니다. 이 기간을 개인정보처리방침에도 적습니다.
7. 반영 뒤에는 '보고서 → 참여도 → 이벤트'에서 아래 항목을 볼 수 있습니다.
   - `click_chat`: 메신저 버튼 클릭 (어떤 앱인지 포함)
   - `click_call`: 전화 클릭 (한국어 사이트)
   - `generate_lead`: 상담 신청서 제출
   - 관리 → 이벤트에서 `click_chat`, `generate_lead` 를 **'주요 이벤트(전환)'**로 표시해 두면 보기 편합니다.

### 1-5. 네이버 애널리틱스
네이버에서 들어온 방문을 더 자세히 봅니다.
1. https://analytics.naver.com 에 사무소 네이버 계정으로 들어가 **'사이트 등록'**을 누릅니다.
2. 사이트 이름(법률사무소 지산)과 URL(`jisanlaw.com`)을 넣습니다.
3. 발급된 **사이트 ID**(영문·숫자로 된 값, 스크립트의 `wcs_add["wa"] = "..."` 부분)를 Claude에게 전달합니다.

### 1-6. 개인정보처리방침 확정
초안은 `docs/legal/privacy-policy-draft.md` 에 있습니다.
1. 아래 빈칸을 정합니다.
   - **상담 기록 보유 기간:** 수임하지 않은 상담을 몇 년 보관할지. 이해충돌 확인용으로 보관한다면 그 목적도 적습니다.
   - **개인정보 보호책임자:** 성명, 직책, 전화, 이메일
   - **Supabase 서버 위치:** https://supabase.com/dashboard 에 로그인 → 프로젝트 → **Project Settings → General**의 'Region'
   - **AI 번역 도구:** 직원이 쓸 서비스 이름. 3-5 참고.
   - **시행일**
2. 담당 변호사가 초안 전체를 개인정보보호위원회 「개인정보 처리방침 작성지침」(privacy.go.kr)과 대조합니다.
3. 확정한 내용을 Claude에게 보내 주시면 한국어·외국어 5개 언어 방침 페이지와 상담 신청서 동의 문구를 함께 바꿉니다.

## 2. 이번 달: 지도·프로필 등록

### 2-1. 네이버 스마트플레이스 (네이버 지도·플레이스)
"서초 형사변호사"처럼 지역 검색을 하면 맨 위에 지도와 업체 목록이 먼저 나옵니다. 여기에 나오려면 등록이 필요합니다.
1. https://new.smartplace.naver.com 에 사무소 네이버 계정으로 들어가 **'업체 신규등록'**을 누릅니다.
2. 업종은 **'법률사무소'**(또는 '변호사')를 고르고, 상호·주소·전화번호를 넣습니다.
3. **사업자등록증**을 올려 인증합니다. 심사에 며칠 걸립니다.
4. 등록 뒤 아래를 채웁니다.
   - **사진:** 사무실 외관·입구·상담실, 변호사 프로필. 처음 보는 사람이 건물을 찾을 수 있게 입구 사진을 꼭 넣으세요.
   - **영업시간**
   - **홈페이지:** `https://jisanlaw.com`
   - **카카오톡 채널, 예약·톡톡** 사용 여부
   - **소개글:** 광고 규정상 '전문', 승소율, '무료' 표현 금지
5. 인천 분사무소는 주소가 있으니 같은 방법으로 따로 등록합니다. 홍성·송파는 주소가 정해진 뒤에 등록합니다.

### 2-2. 구글 비즈니스 프로필
구글 지도와 구글 검색 오른쪽 업체 카드에 나옵니다. 외국인은 대부분 구글 지도로 찾습니다.
1. https://business.google.com 에서 **'지금 관리'**를 누르고 사무소 구글 계정으로 로그인합니다.
2. 업체 이름은 영문 **Jisan Law**로 넣습니다. 한국어 이름은 나중에 추가할 수 있습니다.
3. 카테고리는 기본 **Law firm**, 추가로 Immigration attorney, Criminal justice attorney, Divorce lawyer 등을 넣습니다. 목록은 `docs/marketing/posts/google-business-profile-en.md` 에 있습니다.
4. '고객이 방문할 수 있는 위치가 있나요?' → **예**. 주소를 넣고 지도 핀 위치를 확인합니다.
5. 전화번호와 웹사이트(`https://jisanlaw.com/en`)를 넣습니다.
6. **소유 확인:** 구글이 고르는 방법(영상 촬영, 전화·문자, 우편 엽서 등)으로 확인합니다.
   - 영상 확인이면 사무실 간판, 주소 표시, 사무실 내부, 사업자등록증을 한 번에 찍습니다.
   - 확인에 며칠~2주 걸릴 수 있습니다.
7. 확인 뒤 `google-business-profile-en.md` 의 소개문(750자 이내), 서비스 목록, 첫 게시물 2개를 붙여 넣습니다.
8. 영업시간과 사진(외관·입구·내부·변호사)을 넣습니다.
9. 프로필 링크를 Claude에게 보내 주시면 홈페이지 '오시는 길'에 연결합니다.

### 2-3. 카카오맵 장소 등록
1. 카카오맵 앱이나 https://place.map.kakao.com 에서 사무소 주소를 검색합니다.
2. 장소가 없으면 **'장소 등록'**, 정보가 틀렸으면 **'정보 수정 제안'**을 누릅니다.
3. 사업자는 카카오 비즈니스(business.kakao.com)에서 **'내 장소 관리'**로 직접 관리할 수 있습니다. 카카오톡 채널과 연결할 수 있습니다.

### 2-4. 의뢰인 후기 받기
후기 수와 최근성은 지도 검색 순위에 크게 영향을 줍니다.
1. 구글 비즈니스 프로필 화면의 **'리뷰 요청'**(또는 '고객에게 리뷰 요청') 버튼으로 후기 작성 링크를 받습니다. 네이버 플레이스도 리뷰 링크나 QR을 받을 수 있습니다.
2. 사건이 끝난 의뢰인에게 감사 인사와 함께 링크를 보내는 순서를 정합니다. 예: 종결 안내 문자 끝에 한 줄.
3. **하면 안 되는 것:**
   - 후기 대가로 금전·할인 제공
   - 직원·지인이 쓰는 후기
   - 특정 내용으로 써 달라는 요청
   - 승소율·결과 보장처럼 읽히는 후기를 홍보에 다시 쓰는 것
4. 후기에는 2~3일 안에 정중하게 답글을 답니다. 사건 내용은 답글에 쓰지 않습니다(비밀유지).

## 3. 외국인 고객 경로

### 3-1. 위챗 (중국어권)
1. 업무용 휴대폰에 WeChat을 설치하고 사무소 명의로 가입합니다. 가입 때 기존 사용자 인증이나 친구 인증을 요구할 수 있습니다.
2. **나 → 프로필 → WeChat ID**에서 ID를 정합니다(1년에 한 번만 바꿀 수 있음).
3. **나 → 프로필 → 내 QR 코드**를 캡처합니다.
4. ID와 QR 이미지를 Claude에게 전달하면, 중국어 사이트 맨 앞 버튼으로 넣고 누르면 ID 복사와 QR이 나오게 합니다.

### 3-2. Zalo (베트남어권)
1. Zalo 앱을 설치하고 사무소 휴대폰 번호로 가입합니다.
2. 개인 계정의 연결 링크는 `https://zalo.me/전화번호`(예: `https://zalo.me/8210xxxxxxxx`) 형식입니다.
3. 사무소 공식 계정이 필요하면 **Zalo Official Account**(oa.zalo.me)를 만듭니다. 사업자 인증이 필요합니다.
4. 링크를 Claude에게 전달합니다.

### 3-3. 페이스북 메신저 (몽골어권, 선택)
1. 페이스북에서 **'페이지 만들기'**로 사무소 페이지(Jisan Law)를 만듭니다.
2. 페이지 사용자 이름(예: `jisanlaw`)을 정하면 메신저 링크는 `https://m.me/jisanlaw` 입니다.
3. 링크를 Claude에게 전달합니다. 이 페이지는 몽골인·베트남인 페이스북 그룹에 글을 올릴 때도 씁니다.

### 3-4. WhatsApp 업무용 계정으로 바꾸기
지금 버튼은 김한솔 변호사 개인 WhatsApp으로 연결됩니다. 직원이 응대하려면 업무용 계정이 낫습니다.
1. 사무소 업무용 휴대폰에 **WhatsApp Business** 앱을 설치하고 사무소 번호로 가입합니다.
2. **설정 → 비즈니스 도구 → 비즈니스 프로필**에 사무소 이름, 주소, 웹사이트, 소개를 넣습니다.
3. **비즈니스 도구 → 인사 메시지·부재중 메시지**에 3-6의 첫 응대 문구를 넣습니다.
4. **설정 → 비즈니스 도구 → 짧은 링크**에서 `wa.me/...` 링크를 복사해 Claude에게 전달합니다.
   - 개인 계정을 계속 쓰신다면, **설정 → QR 코드 재설정**을 누르면 지금 링크가 끊어지니 누르지 마세요.

### 3-5. 텔레그램 정리
1. 텔레그램 **설정 → 프로필 편집**에서 이름을 'Jisan Law'로, 소개(Bio)에 `jisanlaw.com` 을 넣습니다.
2. 개인 계정이면 **설정 → 개인정보 및 보안**에서 전화번호 공개를 '아무도'로 바꿉니다.
3. 여러 직원이 응대하려면 텔레그램 Business 기능이나 그룹 대신, 한 업무용 계정을 업무 휴대폰과 PC(Telegram Desktop)에 같이 로그인해 쓰는 방법이 간단합니다.

### 3-6. 메신저 첫 응대 문구 정하기
모든 메신저에 같은 순서로 답하면 직원 교육과 기록이 쉬워집니다.
1. 정할 내용:
   - 인사와 사무소 소개 한 줄
   - 받을 정보: 이름, 연락할 메신저, 무슨 일인지, 받은 서류와 거기 적힌 기한, 지금 위치(구금 여부)
   - 상담료 안내 여부와 방식
   - "직원이 먼저 확인하고 변호사에게 전달한다"는 안내
   - 개인정보 안내 한 줄 (개인정보처리방침 링크)
2. 원하시면 Claude가 6개 언어(한·영·중·베·러·몽) 초안을 써 드립니다.
3. 정한 문구는 WhatsApp Business·카카오톡 채널의 자동 인사에 넣고, 텔레그램·위챗은 빠른 답장(즐겨찾기 메시지)에 저장해 둡니다.

### 3-7. AI 번역 도구 정하기
의뢰인이 보낸 내용을 번역 도구에 넣는 것은 개인정보를 외부 회사에 맡기는 것입니다.
1. 업무용 요금제를 쓰는 도구를 고릅니다. 예: 기업용 번역 서비스, 업무용 AI 요금제. 확인할 점은 아래와 같습니다.
   - 입력 내용을 **학습에 쓰지 않는지**
   - 보관 기간
   - 서버 국가
2. 확인할 곳: 각 서비스의 개인정보처리방침·데이터 처리 약관(DPA). 대부분 '비즈니스/엔터프라이즈' 요금제에서 학습 제외가 기본입니다.
3. 직원 규칙을 정합니다.
   - 주민등록번호·여권번호 같은 고유식별번호는 지우고 번역합니다.
   - 개인 계정이 아닌 사무소 계정만 씁니다.
4. 정한 도구 이름, 회사, 국가, 보관 기간을 Claude에게 알려 주시면 개인정보처리방침 위탁·국외이전 표에 넣습니다.

## 5. 광고 (선택)

### 5-1. 네이버 파워링크
1. https://searchad.naver.com 에서 광고주 가입을 하고 사업자 인증을 합니다. 법률 업종은 변호사 등록 증빙을 요구할 수 있습니다.
2. 캠페인 유형은 **'파워링크'**입니다.
3. 키워드는 사건명 중심으로 정합니다. 예: 음주운전 변호사, 상간소송, 상속포기, 이혼 재산분할.
4. **연결 URL은 메인이 아니라 해당 상세 페이지로** 정합니다. 예: 음주운전 → `jisanlaw.com/crime/drunk-driving`.
5. 하루 예산을 작게 시작해 2주 뒤 클릭·문의 수를 보고 조정합니다.

### 5-2. 구글 광고 (외국인)
1. https://ads.google.com 에서 계정을 만들고, 애널리틱스(1-4)와 연결합니다.
2. **검색 캠페인**을 만들고, 지역은 대한민국, 언어는 대상 언어로 정합니다.
3. 키워드 예:
   - 영어: lawyer Korea visa, deportation lawyer Korea
   - 중국어: 韩国律师 签证
   - 베트남어: luật sư Hàn Quốc
   - 각각 `/en/foreigner`, `/zh/foreigner`, `/vi/foreigner` 로 연결합니다.
4. 전환(목표)을 애널리틱스의 `click_chat` 으로 정하면 메신저 문의가 생기는 광고에 예산이 몰립니다.

### 5-3. 광고 문구 검토
변호사 광고 규정(변호사업무광고규정)상 금지:
- '전문' 표시 (등록한 전문분야가 아니면)
- 승소율·석방률
- 결과 보장
- '무료' 같은 대가 표시
- 비교·비방
- 사실과 다른 경력

원하시면 Claude가 광고 문구 초안을 쓰고, 규정에 걸리는 표현이 없는지 점검해 드립니다.
